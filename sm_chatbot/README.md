# React Chatbot Frontend

This is the frontend for a real-time chatbot web application built using **React**, **Tailwind CSS**, and **Ant Design**. It includes **user authentication with JWT**, **protected routes**, and **real-time WebSocket communication** with the backend.

## 🚀 Features

- User authentication (login with JWT)
- Protected routes (chatbot only accessible after login)
- Chatbot interface with real-time WebSocket communication
- Responsive UI with **Tailwind CSS** and **Ant Design**
- Session management (JWT stored in `localStorage`)

---

## 📌 Technologies Used

- **React** (Frontend framework)
- **Vite** (Fast build tool for React)
- **Tailwind CSS** (Utility-first styling framework)
- **Ant Design** (Pre-styled UI components)
- **React Router** (Navigation and route protection)
- **Axios** (API requests)
- **WebSockets** (Real-time chatbot communication)
